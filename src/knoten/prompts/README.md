# knoten stage prompts

One prompt per stage. Each says, in the same order: what the node is, the frontmatter the
graph's rules demand (links, fields), the body sections in order, and what comes next.

- `prompt-question.md`   the root everything descends from
- `prompt-source.md`     what you read, and where to look when you have no ideas
- `prompt-idea.md`       a direction, from a source or a finding
- `prompt-hypothesis.md` one claim and the number that kills it
- `prompt-experiment.md` the rerunnable test and its raw numbers
- `prompt-finding.md`    what the numbers mean, alive or dead
- `prompt-gate.md`       a standing check a result should survive

Read the one for the stage you are about to write. Never write a node from another
stage's prompt: a hypothesis is not a finding. Each stage cites the stage before it;
that edge is what makes this a graph. When the well is dry, `prompt-source.md` says
where to go.
