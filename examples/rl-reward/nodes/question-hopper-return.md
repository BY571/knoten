# What gets a PPO agent past return 15 on the hopper task within 1M steps?

## The bar
Mean return over at least three seeds at 1M environment steps, with the standard
deviation reported. A single lucky seed is not a result.

## What "answered" looks like
A configuration that reaches return 15 on three seeds, and a general statement of
why the changes that got there worked.
